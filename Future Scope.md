***# How would you improve the project in the future?***

Future enhancements include:



SBOM support using CycloneDX and SPDX

Nessus or Active Network/System Scanning

Authentication and RBAC

Multi-tenant support

Asset inventory integration

CVE notification system

Advanced analytics dashboards

Machine learning-based vulnerability prioritization (if justified by requirements)

Integration with SIEM platforms such as Splunk or Elastic Security
